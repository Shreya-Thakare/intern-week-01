# 10-Day Intern Technical Training & Domain Assessment

Self-study · Hands-on practice · Technical assessment

## Submission structure

```text
INTERN-WEEK/
├── day-01/   Programming fundamentals, DSA, Git, Employee CLI
├── day-02/   Python development, management system, CSV analysis
├── day-03/   NumPy, Pandas, visualization
├── day-04/   Machine learning prediction
├── day-05/   Modern JavaScript employee dashboard
├── day-06/   TypeScript + React (+ standalone index.html)
├── day-07/   Next.js + Node.js full-stack API
├── day-08/   SQL + Laravel CRUD API
├── day-09/   Angular facility inspection dashboard
└── day-10/   Final project (ML + dashboard + Angular module)
```

## Quick start by day

| Day | How to run |
|-----|------------|
| 1 | `cd day-01/employee-management && python main.py` |
| 2 | `cd day-02/management-system && python student_management.py` |
| 3 | `cd day-03 && python data-cleaning/clean_data.py` |
| 4 | `cd day-04 && pip install -r requirements.txt && python run_project.py` |
| 5 | Open `day-05/employee-dashboard/index.html` |
| 6 | Open `day-06/index.html` **or** `cd day-06/react-app && npm i && npm run dev` |
| 7 | Terminal 1: `cd day-07/node-api && npm i && npm start` · Terminal 2: `cd day-07/nextjs-app && npm i && npm run dev` |
| 8 | `python day-08/run_sqlite_demo.py` **or** import `sql/*.sql` into MySQL |
| 9 | `cd day-09/angular-app && npm i && npm start` |
| 10 | Open `day-10/final-project/frontend/index.html` · optional: `python day-10/final-project/backend/run_simple_api.py` |

## Notes

- Each day has its own `README.md` with features, architecture, and challenges.
- Day 10 includes ML model training, FastAPI (or simple API), dark dashboard with prediction visualization, and an Angular module.
- Prefer Python 3.10+, Node 18+.
